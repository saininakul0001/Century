# Century scorekeeper

A single-page scorekeeper for the Century card game. No build step, no dependencies.

## Run locally
Open `index.html` in a browser.

## Put it on GitHub
```
git init
git add .
git commit -m "Century scorekeeper"
git branch -M main
git remote add origin https://github.com/<your-username>/century.git
git push -u origin main
```

## Deploy on Render (free)
1. Sign in at render.com and choose New > Static Site.
2. Connect the GitHub repo.
3. Leave Build Command empty. Set Publish Directory to `.`
4. Create Static Site. Open the `.onrender.com` link on your phone and use Add to Home Screen.
